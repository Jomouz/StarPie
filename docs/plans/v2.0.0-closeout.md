## 级联动作编辑的追加修复

初次独立复核结论为 request changes，以下问题现已修复并独立复核通过：

1. 选择继承子动作不再提前物化，但图标、预设、浏览、布尔与插件参数仍有写入临时有效副本的路径，导致编辑丢失。
2. 中心恢复继承写入 Type=Inherit，当前中心有效动作解析会将它当本地动作返回，不能回退 Global。

4. 整扇区粘贴统计原始空列表，遗漏继承子动作，可能跳过覆盖确认。
5. 新提示与交易说明存在硬编码中文，另有差异尾空格。

后续同类复核还修正了继承主/中心动作的单动作复制、中心拖拽取有效值与保留目标子项、本地化下拉刷新触发写入，以及自动保存提示换语言后保留实际状态。保持原有配置字段，中心恢复继承沿用 Type=None 的既有回退语义，保留启用偏好和未知字段。
