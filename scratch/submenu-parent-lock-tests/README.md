# 二级菜单父扇区锁定验证

从仓库根目录运行：

```powershell
dotnet run --project .\scratch\submenu-parent-lock-tests\SubmenuParentLockTests.csproj -c Release -- --test-instance
```

必须提供 `--test-instance`。验证器隔离 `LOCALAPPDATA`，禁用自动启动同步；构造离屏 WPF 控件和窗口但不调用 `Show`，不安装输入钩子。所有动作派发通过测试观察口截获，不执行真实快捷键、系统音量或窗口操作。不能用它替代用户的视觉、DPI、实际输入和手感验收。

`Program.cs` 覆盖默认关闭、配置往返、4/8/12 扇区、两种子菜单、退回解锁、同时展开、释放和取消。复核修正了原测试中落在禁用子项或图形间隙的进入坐标；有效进入需要命中真实可用子项，而非仅达到半径。

`ReviewRegression.cs` 调用生产控制器、预览和切层入口，覆盖过期显示回调、未展开子环、不可见和占位子项、跨扇区数继承、12 扇区侧翼、相邻音量外甩豁免、缩放预览、透明路径点击以及滚轮/Tab/自定义键切层。新增反例在收到的 Gemini 候选上实际出现 9 项失败后才修复。冻结几何查询另测与渲染几何的一致性及每次查询的托管分配；状态跟踪器微基准不是完整控制器或鼠标到画面的延迟测量。

人工验收：开关关闭和开启分别检查外圈子环与蜂窝扇，向侧翼划动、越过一级边界、退回一级再切换、切层、取消后重开，以及在图形间隙松手。开启同时展开时，一级区域仍可自由切换。桌宠粘滞轮盘不属于此开关范围。
